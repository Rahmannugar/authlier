Authlier is a composable authentication library that runs inside your Go
server. It provides the server-side flows for passwords, sessions, email
verification and recovery, TOTP, passkeys, Google authentication, OIDC, and
SAML SSO.

Configure the sign-in methods your application needs, connect an official
storage adapter, and mount one `http.Handler`. Authentication data stays in the
database you configure. Your application keeps control of profiles, roles, and
permissions.

## How it fits into an application

<AuthFlow />

The client sends authentication requests to the Authlier handler mounted in
your Go server. Authlier verifies the request, stores the authentication
records, and creates a session. Browser applications normally receive an
HttpOnly cookie. Mobile, CLI, and API clients can use access and refresh tokens
instead. Your server resolves the session to a stable subject ID, which your
application uses to load its own data and enforce its own permissions.

## Included authentication methods

| Authentication method | What it provides |
| --- | --- |
| Email and password | Sign-up, sign-in, password changes, and secure password hashing |
| Email verification and recovery | Email ownership verification and password reset flows |
| Google | Google sign-in and account linking |
| TOTP | Authenticator-app verification and recovery codes |
| Passkeys | WebAuthn registration and passwordless sign-in |
| OIDC and SAML | Single sign-on with organization identity providers |

Start with [Getting started](/docs/getting-started) for a complete working Go
