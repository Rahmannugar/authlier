# Authlier documentation design

Authlier's documentation should feel precise, calm, and easy to scan. It uses
the graphite Authlier mark, neutral surfaces, and a clear blue accent. Onest is
the reading font. Bricolage Grotesque gives headings and the brand a distinct
voice. Phosphor is the only icon library used by Authlier's website code.

The site shares its fonts and primary blue with Consumel. The landing page uses
a focused two-band layout: a blue introduction followed immediately by a black
start section. It does not add unrelated marketing sections or resemble a
generic SaaS dashboard.

The documentation shell keeps the article column readable, the sidebar
task-based, and navigation predictable. Introduction pages may use cards and
short diagrams. Feature guides lead with a working setup and move operational
or security detail later in the page.

Light and dark modes must both preserve strong contrast. Interactive controls
need visible focus states and usable pointer targets. Decorative motion is not
needed.
