# Security Policy

Authlier is security-sensitive software. Do not report suspected
vulnerabilities in a public issue.

Until a dedicated security mailbox is published, contact the repository owner
privately through the contact method listed on the owner's GitHub profile.

Include the affected version, a concise description, reproduction details, and
the potential impact. Do not include real credentials, session tokens, personal
data, or secrets in a report.

Authlier uses OWASP ASVS 5.0 and applicable OWASP cheat sheets as engineering
and verification inputs. This statement is not a claim of certification or
complete ASVS compliance.
